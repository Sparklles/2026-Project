# 2026-综合实践-航海产品电子商务网
“航海产品电子商务网”项目旨在帮助拥有目录销售经验的航海用品公司实现互联网销售转型。系统的核心功能需支持用户以多种方式搜索书籍、维护待购清单，并允许用户对所购书籍进行评分和评论。

## 项目结构

- `backend/`：Spring Boot 后端项目
- `frontend/`：前端项目目录

## 后端

```bash
cd backend
./mvnw spring-boot:run
```

## 前端

前端 Vue2 框架相关依赖下载命令：

```bash
cd frontend
npm install
npm i element-ui -S
npm i axios -S
npm run serve
```
